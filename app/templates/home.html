Come funziona

  1. 1 Inserisci i dati principali (età, RAL, anno di assunzione).
  2. 2 Personalizza ipotesi e versamenti volontari se desideri.
  3. 3 Visualizza i risultati e scarica il PDF condivisibile.

Perché usarlo

  • Ti aiuta a capire l'impatto della fiscalità sul capitale finale.
  • Offre una visione comparativa, utile per decisioni informate.
  • Riduce il tempo necessario per preparare una consulenza.
I risultati sono stime basate sulle ipotesi inserite e non rappresentano garanzia di rendimento.

Strumento a scopo informativo: non costituisce consulenza finanziaria, fiscale o previdenziale personalizzata.

Allinea GitHub & Render

Da questa pagina non posso fare il push automaticamente: serve il tuo PC. Però qui trovi i passaggi esatti.

1) Allinea la tua cartella locale
git status
git add .
git commit -m "Sync locale con GitHub"
git push
2) Controlla GitHub

Verifica che su GitHub ci siano requirements.txt e app/main.py.

3) Imposta Render
Start command:
python -m uvicorn app.main:app --host 0.0.0.0 --port 10000

Assicurati che Render usi lo stesso branch del tuo push.

Se vuoi, puoi tenere aperta questa guida mentre fai i passaggi sul tuo PC.
